# Animations de physique

Animations interactives construites en révisant la physique en MPI*.

- **Moteur Stirling alpha** : bielles, vilebrequin et cycle de Clapeyron calculé (modèle de Schmidt).
- **Surface P-v-T d'un corps pur** : surface 3D orientable et ses projections (P, v) et (P, T).

Tout tient dans un seul fichier `index.html` (HTML + CSS + JavaScript, sans dépendance), publié avec GitHub Pages.

Site : https://nathandidr.github.io/physique/
